# ADR-006: 暂停占位式 L3 校验

| 属性 | 值 |
| ---- | -- |
| 状态 | Accepted |
| 日期 | 2026-07-10 |
| Supersedes | — |

> 本 ADR 源自 `docs/rfcs/RFC-001-pause-placeholder-l3.md`。

## 决策背景

当前 L3 只比较两份人工维护的相同文件，没有运行 Skill，却会以快照通过的形式呈现。

## 最终决定

在具备可重复的 Agent runner 前暂停 L3。保留 `snapshot` CLI 参数，但只输出一次未执行提示；行为场景、rubric 和期望输出继续作为人工前向测试资产维护。

## 决策理由

重复文件比较不能证明 Skill 行为。明确暂停比保留假阳性更可靠，也无需提前引入模型、费用和稳定性基础设施。

## 影响后果

- L0、L1、L2 继续作为自动质量门禁
- L3 暂不提供自动行为验证
- 现有 CI 命令保持兼容
- 恢复 L3 需要新的 RFC 定义 runner 和评分接口

## 替代方案

- 立即实现 Agent runner：当前缺少运行环境和稳定性约束
- 保留重复文件比较：没有有效质量信号

## 后续动作

需要严格输出验证时，为真实 L3 runner 编写独立 RFC。
