# matharts-doc-readme

生成和审查 MathArts 项目的 `README.md`。

## 职责

- 为新项目生成结构化 README.md
- 审查现有 README.md 的完整性
- 统一 MathArts 项目的 README 结构

## 依赖

- `matharts-doc-design` — 继承排版规则

## 安装

```bash
npx skills add matharts/skills --skill matharts-doc-readme -a opencode
```

## 状态

`experimental` — 结构和规则可能变化。
