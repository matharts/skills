# Rewrite Summary Example

Use this shape after directly optimizing, rewriting, organizing, or standardizing a document.

```markdown
已优化：README.md

主要调整：
- Reordered the document around the reader task path: positioning, quick start, common tasks, documentation, and contribution flow.
- Replaced vague headings with concrete open source documentation headings.
- Moved commands into language-tagged code blocks and grouped repeated commands into a task table.
- Added `TODO:` markers for missing owner and support-channel facts instead of inventing them.
```

## Rewrite Rules

- Summarize the kind of change, not every line touched.
- Mention when uncertain facts were marked instead of invented.
- Keep the summary short enough that the optimized document remains the main artifact.
